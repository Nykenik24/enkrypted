# enkrypted

Safe, private and FOSS P2P/Client-Server E2EE chat app made in Go.

## Usage

Run: 

```bash
go run cmd/server/main.go
```

Then use a client that supports WS (e.g. Postman, Hoppscotch...) or run the frontend:

```bash
cd chat-ui
npm run start # or npm run dev
```
