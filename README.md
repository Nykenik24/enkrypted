# enkrypted

Safe, private and FOSS P2P/Client-Server E2EE chat app made in Go.

## Usage

```bash
go run cmd/server/main.go
```

Then go to `http://localhost:8080` (or whatever port you chose).

## Disclaimer

**Yes**, the frontend was made with AI. It's temporary, it will be replaced by a
human-made one. For now, it's just for testing.
